## Scope

Steps 13-16 resolve all 77 `derive-composite` records from the reviewed Office
Geometry v3 audit without repainting, regenerating, or replacing source art.
The resolution is intentionally split into four independently counted waves:

| Wave | Scope | Records |
| --- | --- | ---: |
| Step 13 | Static cleanup | 24 |
| Step 14 | Animation-frame cleanup | 40 |
| Step 15 | Library furniture/facility composites | 6 |
| Step 16 | Legacy runtime composites in staging | 7 |

The machine-readable acceptance source is
`assets/game/manifests/office-derived-assets-v1.json`. It records source and
output hashes, immutable source paths, cleanup envelopes, foreground regions,
pixel counts, Geometry v3 metadata, and QA boards for every audit record.

## Results

- 64 cleanup records produce versioned clean outputs.
- 48 cleanup records remove 89,915 reviewed adjacent-cell alpha pixels.
- 16 cleanup records have one coherent alpha component in the current reviewed
  source. Their pixels are retained exactly as `verified-noop-cleanup` rather
  than deleting pixels without a defensible component boundary.
- 13 furniture or structural records produce exact source-pixel base layers.
- 12 of the composites also produce source-pixel foreground overlays. The
  semantic door composite has no artificial foreground mask.
- 89 versioned runtime image outputs and four QA boards are locked by hash.
- The original 77 source files remain unchanged and continue to serve as
  provenance.

## Deterministic gates

`scripts/build-office-derived-assets.py` fails when a reviewed source hash
drifts, when the 24/40/6/7 wave allocation changes, or when generated bytes do
not match the committed outputs. The portable Node check verifies all 77 audit
IDs, hashes, alpha accounting, Geometry v3 contracts, exact output paths, QA
boards, and Active Office isolation.

Run the art-workstation and portable checks with:

```bash
npm run art:derived:check
npm run art:derived:contract:check
npm run check
```
