## Values that remain valid as shared scale evidence

- one world tile is 32 authoring pixels;
- X increases right, Y toward the viewer, and Z upward;
- a person reserves `1 x 1` and has logical height `3`;
- a chair reserves `1 x 1` and has logical height `2`;
- a desk reserves `3 x 2`, has logical height `2`, and owns a complete
  `96 x 64` support plane;
- monitor and keyboard bitmaps do not define their reservations.

These values remain valid only where they agree with the approved R05-r02
manifest and coordinate manual.
