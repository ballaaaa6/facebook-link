# Modern Bright Office Asset Library v1

This directory contains extracted, alpha-keyed candidates from the eight
approved modern-bright office source sheets.

## Status

- Library-ready: yes
- Runtime-registered: no
- Placed on an office map: no

The source sheets remain under `assets/art/layout-references/`. Every PNG in
this directory is generated by:

```bash
npm run art:library
```

Validate the stored files without rewriting them:

```bash
npm run art:library:check
```

The cell mapping, source bounds, output paths, geometry, supports, anchors, and
animation metadata are recorded in
`assets/game/manifests/office-library-sheets.json`.

Animated rows use four true frames named `a`, `b`, `c`, and `d`, intended to
play as `a-b-c-d-a`. Runtime atlas packing, asset registry imports, and map
placement are intentionally deferred.
