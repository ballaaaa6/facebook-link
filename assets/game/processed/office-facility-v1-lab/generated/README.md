# Rectangular workstation v5 source

`workstation-rectangular-pair-v5-chroma.png` was generated with the built-in
image-generation tool from the staged viewer-front and viewer-back workstation
references.

The production prompt requested exactly two matched modern-bright pixel-art
desks, a uniform `#00ff00` background, full rectangular tabletop silhouettes,
square 90-degree corners, identical baselines, and no people, chairs,
equipment, props, labels, logos, shadows, or extra furniture. The logical
contract was a `5 x 4` desk with a `5 x 3` usable surface: six prop cells on the
left, an employee-relative monitor/keyboard/clear center lane, and six prop
cells on the right.

This chroma source is provenance only. Runtime imports the processed RGBA files
from `../derived/`.
